# Questions on the Mathura–Nagda 3rd line Plan & L-Section sheets (94–102)

Answers were looked for in this order: the sheet's right-hand panel (notes, legend, abbreviations), the
drawing's own numbers, the internet, and only then Ankur. Each settled item says where its answer came from.

## Settled

| # | Question | Answer | Source |
|---|---|---|---|
| 1 | Curve point labels | A curve runs **ST → TC → CT → TS** (S = straight, T = transition, C = circular). The same points are **TTP1, CTP1, CTP2, TTP2** in the abbreviations table; other drawing sets may print those names | Ankur; abbreviations; gaps equal TRL/CCL/TRL on 29 of 30 curves |
| 3 | Curve box fields | R radius, TL tangent length, TRL transition length, CCL circular curve length, Δ angle. **Shift = TRL²/24R** (35/35 curves), **TTL = (R + Shift)·tan(Δ/2) + TRL/2** = total tangent length from IP to TTP1 (35/35), **Degree = 1750/R** (Indian Railways 30.5 m chord) | Abbreviations; checked on the drawing's numbers |
| 5 | Left hand / right hand | As seen travelling towards **increasing chainage**: the bearing turns clockwise across every RH curve (27/27); the bearing change equals Δ (26/27) | Drawing's bearings and curve boxes |
| 6 | Plan gradient labels | Grade change symbols: stem `CH`/`FL`, gradient **before** on the left of the bar, **after** on the right. `N F/R` = 1 in N falling/rising; huge N or `LEVEL` = level. Red = proposed 3rd line (proposed chainage), black = existing UP line (existing km). 120/121 chain correctly, 124/126 agree with the FLs | Ankur's marked-up screenshot; checked on all sheets |
| 7 | `LEVEL` | A level stretch of the existing UP line | Same as 6 |
| 9 | Vertical curves | Not drawn: **note 7**, "provided at site" where the grade difference is 0.4% or more (BVC/EVC/PVI in the abbreviations) | Note 7 |

| 11 | RL | **Rail level = FL + 0.762** (note 5: 762 mm above formation); true in every band column | Note 5; abbreviations |
